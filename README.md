# Financial_Profitability_analysis
Financial performance and profitability analysis using  sql ,excel and Power bi
inancial Profitability Analysis 

About the Project 

This project is about analyzing financial data to understand how the business is performing. I worked with revenue, expenses, profit, customers, products, and regional data to find useful business insights. 

The main goal was to understand where the business is performing well, where it is losing money, and which areas have better profitability. 

Business Problem 

The business has a large amount of financial data, but it is difficult to understand the overall performance just by looking at the raw data. 

This project helps answer questions such as: 

How much revenue and profit is the business generating? 

How are expenses affecting profit? 

Which products are performing well? 

Which regions are more profitable? 

How does performance change month by month? 

Which areas need more attention? 

What I Did 

Cleaned and prepared the data for analysis 

Used SQL to analyze the data and calculate important metrics 

Used Excel for data checking and additional analysis 

Created KPIs and charts in Power BI 

Analyzed revenue, expenses, profit, and profit margin 

Compared performance across products, customers, and regions 

Identified important trends and areas that need improvement
